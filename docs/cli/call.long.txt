Call Variants from Sequence Graph

Usage: Himito call [OPTIONS] --graphfile <GRAPHFILE> --reference-fasta <REFERENCE_FASTA> --sample-id <SAMPLE_ID> --output-file <OUTPUT_FILE>

Options:
  -g, --graphfile <GRAPHFILE>
          anchor graph (GFA)

      --threads <THREADS>
          worker threads for parallel stages

  -r, --reference-fasta <REFERENCE_FASTA>
          reference FASTA (rCRS)

  -s, --sample-id <SAMPLE_ID>
          sample name written to the VCF

  -d, --data-type <DATA_TYPE>
          sequencing data type; sets the filter presets
          
          [default: pacbio]
          [possible values: pacbio, ont-r9, ont-r10, ont-denoised]

  -o, --output-file <OUTPUT_FILE>
          output VCF path

  -b, --bam <BAM>
          raw pre-denoise BAM: strand filter, linkage rescue, matrix.csv

  -k, --k <K>
          k-mer size of the anchor graph
          
          [default: 21]

  -m, --minimal-ac <MINIMAL_AC>
          minimum allele count for a variant
          
          [default: 2]

  -v, --vaf-threshold <VAF_THRESHOLD>
          minimum heteroplasmic frequency for a variant (preset by data type)

  -p, --p-value-threshold <P_VALUE_THRESHOLD>
          permutation-test p-value cutoff; 1 disables it (preset by data type)

  -f, --frequency-threshold <FREQUENCY_THRESHOLD>
          permutation-test frequency threshold (preset by data type)

      --strand-bias-threshold <STRAND_BIAS_THRESHOLD>
          p-value cutoff of the strand-bias filter (only used with --bam)
          
          [default: 0.01]

      --indel-false-threshold <INDEL_FALSE_THRESHOLD>
          indels below this HF are flagged Potential_Artifact (preset by data type)

      --permutation-frequency-threshold <PERMUTATION_FREQUENCY_THRESHOLD>
          variants above this matrix frequency skip the permutation test (preset)

      --permutation-rounds <PERMUTATION_ROUNDS>
          minimum permutation rounds per tested variant
          
          [default: 1000]

      --no-left-align
          keep the graph's indel spellings instead of left-aligning them

  -h, --help
          Print help (see a summary with '-h')
