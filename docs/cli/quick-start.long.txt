Quick start pipeline for mitochondrial assembly, variant calling and methylation aggregation

Usage: Himito quick-start [OPTIONS] --input-bam <INPUT_BAM> --reference-path <REFERENCE_PATH> --sample-id <SAMPLE_ID> --output-prefix <OUTPUT_PREFIX>

Options:
  -i, --input-bam <INPUT_BAM>
          input BAM of reads, coordinate-sorted

      --threads <THREADS>
          worker threads for parallel stages

  -c, --chromo <CHROMO>
          mitochondrial contig name in the BAM
          
          [default: chrM]

  -r, --reference-path <REFERENCE_PATH>
          reference FASTA (rCRS)

  -s, --sample-id <SAMPLE_ID>
          sample name written to the outputs

  -d, --data-type <DATA_TYPE>
          sequencing data type; sets the filter and denoise presets
          
          [default: pacbio]
          [possible values: pacbio, ont-r9, ont-r10, ont-denoised]

  -o, --output-prefix <OUTPUT_PREFIX>
          output prefix for the BAM, GFA, VCF, matrix and BED outputs

      --maximal-mt-depth <MAXIMAL_MT_DEPTH>
          maximum mtDNA reads kept after downsampling
          
          [default: 50000]

  -t, --threshold-methylation-prob <THRESHOLD_METHYLATION_PROB>
          minimum probability to call a C methylated
          
          [default: 0.5]

  -f, --filter-max-methylation <FILTER_MAX_METHYLATION>
          maximum methylated fraction for a read to count as mtDNA
          
          [default: 0.2]

  -k, --kmer-size <KMER_SIZE>
          k-mer size of the anchor graph
          
          [default: 21]

  -m, --minimal-ac <MINIMAL_AC>
          minimum allele count for a variant
          
          [default: 2]

  -v, --vaf-threshold <VAF_THRESHOLD>
          minimum heteroplasmic frequency for a variant (preset by data type)

      --p-value-threshold <P_VALUE_THRESHOLD>
          permutation-test p-value cutoff; 1 disables it (preset by data type)

      --heteroplasmic-frequency-threshold <HETEROPLASMIC_FREQUENCY_THRESHOLD>
          permutation-test frequency threshold (preset by data type)

      --strand-bias-threshold <STRAND_BIAS_THRESHOLD>
          p-value cutoff of the strand-bias filter
          
          [default: 0.05]

      --indel-false-threshold <INDEL_FALSE_THRESHOLD>
          indels below this HF are flagged Potential_Artifact (preset by data type)

      --permutation-frequency-threshold <PERMUTATION_FREQUENCY_THRESHOLD>
          variants above this matrix frequency skip the permutation test (preset)

      --permutation-rounds <PERMUTATION_ROUNDS>
          minimum permutation rounds per tested variant
          
          [default: 1000]

      --no-left-align
          keep the graph's indel spellings instead of left-aligning them

      --no-linkage-rescue
          turn off read-linkage rescue of low-frequency SNVs (ONT only)

      --denoise-keep-vaf <DENOISE_KEEP_VAF>
          keep threshold of the denoise site model (ont-denoised only)
          
          [default: 0.03]

  -h, --help
          Print help (see a summary with '-h')
