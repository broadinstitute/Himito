Infer mitochondrial lineage from read haplotypes using heteroplasmic SNVs by default

Usage: Himito lineage [OPTIONS] --matrix-file <MATRIX_FILE> --output-prefix <OUTPUT_PREFIX>

Options:
  -m, --matrix-file <MATRIX_FILE>      Himito matrix CSV (<prefix>.matrix.csv)
      --threads <THREADS>              worker threads for parallel stages
  -v, --vcf-file <VCF_FILE>            Himito VCF; restricts the analysis to its heteroplasmic sites
  -d, --data-type <DATA_TYPE>          sequencing data type; sets the SCITE error-rate preset [default: pacbio] [possible values: pacbio, ont-r9, ont-r10, ont-denoised]
  -o, --output-prefix <OUTPUT_PREFIX>  output prefix; writes <prefix>.haplotype_map.tsv and the trees
      --min-hf <MIN_HF>                minimum heteroplasmic frequency (inclusive) of a variant [default: 0.01]
      --max-hf <MAX_HF>                maximum heteroplasmic frequency (exclusive); excludes fixed variants [default: 0.95]
      --include-non-snvs               include heteroplasmic indels and other non-SNV alleles in the tree
  -h, --help                           Print help (see more with '--help')
